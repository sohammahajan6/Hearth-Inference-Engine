About

      

        
What is this?

        
A language-model engine that runs AI models entirely on this PC: nothing you type leaves it, and no internet is needed.

        
Which models work?

        
GGUF files (the format llama.cpp uses) of the Llama 3 family (Llama 3, 3.1, 3.2 and models built on them) and the Qwen2.5 family, in the number formats Q8_0, Q4_0, Q4_K_M, Q5_K_M, Q3_K_M, Q2_K, Q5_0, Q5_1, Q4_1, F16, BF16 and F32. Every file in the Models list is checked when it appears: ready runs on the CPU and the GPU, CPU only on the processor, and not supported says why.

        
How do I add a model?

        
Press Add model… and choose a .gguf file, or paste its path under System → Models, or put it in a folder named models next to hearth.exe. Models are on sites such as Hugging Face: search for the model's name with "GGUF". Use each model under its own license.

        
CPU or GPU?

        
The model runs on one engine at a time. CPU (the processor) is the default. GPU (the graphics chip) runs the whole model through Vulkan; it needs a Q8_0 or Q4_0 file, and its answers can differ slightly from the CPU's in rare near-ties. Use the Benchmark tab to see which is faster on this PC. If the graphics chip fails, the app continues on the CPU and says so.

        
What do the numbers mean?

        
Reading (prefill) is how fast the model takes in your message; writing (decode) is how fast it produces the reply, one token at a time. A token is a piece of a word: a page of English is about 500 to 700 tokens.
          The draft is a smaller model of the same family that guesses a few words ahead for the main one to check in one pass (speculative decoding); the answers stay the main model's own. Writing mostly waits for memory, so the memory read rate is shown too.

        
How do I close the app?

        
Press Quit, or close the console window that opened with it. After 10 minutes without any activity it closes by itself.
